# VLC Backend API

This directory contains the backend API for the VLC extension project.

## Features
- Communicates with VLC via HTTP API
- Manages watchlist and movie suggestions (using TMDB)
- Handles subtitle generation/fetching (via speech-to-text or subtitle APIs)
